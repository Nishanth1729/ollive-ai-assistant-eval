# Qwen2.5-0.5B-Instruct Personal Assistant

Open-source personal assistant built on [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct).

**Features:**
- Multi-turn conversation with memory
- Built-in calculator tool
- Web search via DuckDuckGo
- Input/output safety guardrails

Part of the Ollive AI Founding AIML Engineer evaluation project.
Companion: Groq-backed frontier assistant.
